# 使用说明

## 环境

- Node.js 18+
- pnpm 10（见仓库根 `packageManager`）
- 训练需本机 [LlamaFactory](https://github.com/hiyouga/LlamaFactory)，命令 `llamafactory-cli` 在 PATH 中，或设置 `LLAMAFACTORY_BIN`
- 量化另需本机 `llama-quantize`；HF 转 GGUF 另需系统 Python 与 llama.cpp 转换脚本

## 安装与启动

在仓库根（克隆下来的目录）：

```bash
pnpm install
pnpm test
pnpm build
pnpm webui
```

默认只监听 `127.0.0.1:5000`。可用环境变量：

- `MODEL_TRAINING_HOST` / `MODEL_TRAINING_PORT`
- `MODEL_TRAINING_DATA`：配置与数据根，默认向上找到含 `pnpm-workspace.yaml` 的仓库根

开发前端：`pnpm dev`（Vite 5173，`/api` 代理到 5000，需同时再开 `pnpm webui`）。

CLI：

```bash
pnpm mtrain --help
pnpm mtrain generate
pnpm mtrain generate-eval
pnpm mtrain train
```

CLI 与 Web 读取同一份 `model-training.config.json`。

验证集由 `generate-eval` 独立检索生成，不会从训练集剥离句子。

## 页面

侧栏菜单来自 `packages/web/src/pages` 各文件的 `export const menu`（标题、图标、顺序）。路由由文件名决定，不要再手写 path。

顶栏可切换浅色、深色、跟随系统（存在浏览器 localStorage，不写入配置文件）。

## 代码规范

```bash
pnpm lint

```
