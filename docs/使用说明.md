# 使用说明

## 环境

- Node.js 18+
- pnpm 10（见仓库根 `packageManager`）
- 训练和评估在 [LlamaFactory](https://github.com/hiyouga/LlamaFactory) WebUI。数据页点「打开 LlamaFactory」会自动启动 `llamafactory-cli webui`（已在跑则复用）。评估在 WebUI 的 Evaluate 页做完后，在同一页折叠里导入预测打分。
- 量化另需本机 `llama-quantize`；HF 转 GGUF 另需系统 Python 与 llama.cpp 转换脚本

## 安装与启动

在仓库根（克隆下来的目录）：

```bash
pnpm install
pnpm test
pnpm build
pnpm webui
```

默认只监听 `127.0.0.1:5000`。可用环境变量：

- `MODEL_TRAINING_HOST` / `MODEL_TRAINING_PORT`
- `MODEL_TRAINING_DATA`：配置与数据根，默认向上找到含 `pnpm-workspace.yaml` 的仓库根

开发时开两个终端：

- `pnpm server:dev`：先编译 core，再热更新（tsx 监听 server，同时 watch 编译 core）。不要在 core 的 `dist/` 还不存在时单独起 server。
- `pnpm dev`：前端 Vite（5173，`/api` 代理到 5000）

只跑打包后的界面用 `pnpm webui`（需先 `pnpm build`）。

### 手动启动 LlamaFactory / SwanLab

```bash
pnpm lf:webui        # http://127.0.0.1:7860
pnpm swanlab:watch   # http://127.0.0.1:5092，日志 outputs/swanlog
```

优先使用仓库旁 `LlamaFactory/.venv`。也可用数据页一键拉起。环境变量：`LLAMAFACTORY_HOME`、`GRADIO_SERVER_NAME` / `GRADIO_SERVER_PORT`、`SWANLAB_HOST` / `SWANLAB_PORT` / `SWANLAB_LOGDIR`。未装 SwanLab 时：`pip install "swanlab[dashboard]"`。

CLI：

```bash
pnpm mtrain --help
pnpm mtrain generate
pnpm mtrain generate-eval
pnpm mtrain export-lf
# 训练请打开 LlamaFactory WebUI，数据集目录选 outputs/lf
```

数据页点「打开 LlamaFactory」会先导出数据集、建空的 `outputs/lf-runs/<id>`（登记在 `outputs/lf-meta/<id>.json`，不要放进 output_dir），再检测 7860；没有服务就自动 `llamafactory-cli webui`（安装目录在设置里）。不必再手动另开终端。在 WebUI 里选 `outputs/lf`（容器内 `/data/outputs/lf`）当数据集目录、选刚建的 `lf-runs/<id>` 当输出目录。

评估：同一页折叠「评估」里准备评估目录，WebUI 切到 Evaluate，填数据集目录、`term_eval`、adapter、输出目录；跑完点「导入预测并打分」。

数据生成默认读 `cache/` 检索缓存。要重新打接口，勾选「不读取检索缓存」，或 CLI `pnpm mtrain generate --no-cache`。

SwanLab：数据页点「打开训练曲线」应拉起 `swanlab watch`（`127.0.0.1:5092`）。在 LlamaFactory Extra 勾选 SwanLab，mode=local，日志目录用本页给出的 `outputs/swanlog`（容器内 `/data/outputs/swanlog`）。开始训练后刷新看板应出现 loss/GPU 曲线。不上云、不需要 API Key。没有训练日志时看板可以是空页。未安装时在 LF 虚拟环境执行 `pip install "swanlab[dashboard]"`。

`save_total_limit` 不要设成 1。不要把 Windows 上的 Node 和容器里的 LlamaFactory 混用。无 GPU 只能做数据。训练和评估会抢同一张 GPU。

调参页对比多次已保存的评估；没有逐条预测不会进综合分，LlamaFactory 的 eval_loss 不能当选参依据。综合分：`0.35*ROUGE-L + 0.25*BLEU-4 + 0.25*exact_match + 0.15*(1-copy_input)`。

CLI 与 Web 读取同一份 `model-training.config.json`。

验证集由 `generate-eval` 独立检索生成，不会从训练集剥离句子。

## 页面

侧栏菜单来自 `packages/web/src/pages` 各文件的 `export const menu`（标题、图标、顺序）。路由由文件名决定，不要再手写 path。

顶栏可切换浅色、深色、跟随系统（存在浏览器 localStorage，不写入配置文件）。
